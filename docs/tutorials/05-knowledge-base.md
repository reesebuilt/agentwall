# Quick Tutorial 05: Use the Agentwall Knowledge Base

Time: 45 seconds
Audience: operator or maintainer

## Goal

Find the right Agentwall reference without leaving the dashboard.

## Walkthrough

1. Open `Knowledge Base` from the dashboard nav.
2. Search for a term like `telegram`, `approval`, `floodguard`, or `runtime`.
3. Use category chips to narrow to Sources, Concepts, Articles, Open Questions, File Structure, Tutorials, or Runtime Context.
4. Open the reference if more detail is needed.

## Proof

Success means the operator can answer "where is the source of truth for this behavior?" from the KB surface.
