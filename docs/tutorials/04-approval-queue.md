# Quick Tutorial 04: Review an Approval

Time: 60 seconds
Audience: operator handling blocked work

## Goal

Make one approval decision from the queue using evidence instead of vibes.

## Walkthrough

1. Open Dashboard.
2. Use the hero "Open top pending" or Priority Queue.
3. Read agent, session, action, risk, and matched rules.
4. Open evidence/audit detail if needed.
5. Approve only if the action is expected and scoped.
6. Deny if the action is unclear, broad, or touches secrets/files from a communication channel.

## Proof

Success means the queue changes state, the action is recorded, and the decision appears in audit evidence.

## Safety note

Never approve a channel-origin filesystem mutation or secret access just to make the queue green.
