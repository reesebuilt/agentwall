# Quick Tutorial 03: Operator View vs Advanced User

Time: 30-45 seconds
Audience: new operator

## Goal

Show why Agentwall defaults to simple Operator View and when Advanced User should be enabled.

## Walkthrough

1. Open Dashboard.
2. Note the focused Operator View: channel guardrails first.
3. Toggle Advanced User.
4. Point out policy, federation, evidence, audit, and runtime telemetry panels.
5. Toggle back to Operator View.

## Proof

Success means the operator understands that Advanced User is depth, not the default workflow.
