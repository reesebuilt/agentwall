# Agentwall Quick Tutorials

Purpose: turn Agentwall from a powerful dashboard into something a first-time operator can use in under five minutes.

## Tutorial format

Each quick tutorial should have:
- goal: what the operator will accomplish
- time: target length, usually 30-90 seconds
- prerequisites: what must already be configured
- walkthrough: exact actions in the dashboard
- proof: what success looks like
- safety note: what should stay blocked or redacted

## Tutorials

1. `01-telegram-answer-only.md` — set a Telegram topic to Answer only and prove containment.
2. `02-run-demo-verification.md` — run demo verification and read the expected deny path.
3. `03-advanced-user-mode.md` — switch from Operator View to Advanced User without getting lost.
4. `04-approval-queue.md` — review, approve, or deny a pending action.
5. `05-knowledge-base.md` — search the Agentwall KB and open the right reference.
6. `06-first-real-telegram-topic.md` — bring up the first live Telegram topic with the bringup helper script and prove containment.

## Writing a tutorial

No real chat ids, thread ids, tokens, hostnames, IP addresses, local paths, or raw log
excerpts in tutorial text or screenshots. Sanitize before committing.
