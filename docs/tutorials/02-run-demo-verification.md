# Quick Tutorial 02: Run Demo Verification

Time: 45-60 seconds
Audience: evaluator or new operator

## Goal

Use synthetic demo verification to understand the Agentwall deny path without touching real runtime actions.

## Walkthrough

1. Open Dashboard.
2. Find the primary verification/demo control.
3. Run the demo verification.
4. Read the hero state and priority queue.
5. Open the audit/evidence detail.
6. Clear demo state when done.

## Proof

Success means the dashboard clearly labels synthetic data, shows expected deny/approval behavior, and leaves no ambiguity that no real runtime action executed.
